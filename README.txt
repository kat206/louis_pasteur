WEBSITE LOUIS PASTEUR — HƯỚNG DẪN
1. Giải nén file ZIP.
2. Mở index.html để xem trang chủ. Các trang còn lại liên kết bằng thanh menu.
3. Để xuất bản lấy link nộp giáo viên: tạo repository GitHub, tải toàn bộ 8 file HTML cùng style.css và script.js lên, sau đó vào Settings > Pages, chọn Deploy from a branch > main > /(root) > Save.
4. Sau khi GitHub Pages xuất bản, link thường có dạng https://TEN-TAI-KHOAN.github.io/TEN-REPOSITORY/
Lưu ý: nội dung được dàn thành 8 trang theo tài liệu ảnh đã gửi. Các liên kết nguồn tham khảo ở trang cuối mở website bên ngoài.
